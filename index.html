74VM 使用帮助

三种模式（顶栏切换，或按 1 / 2 / 3）

  • 📐 原理图：默认模式，拖拽元件、按住引脚拖动连线、实时仿真。
  • 🍞 面包板：真实面包板视图（60 列 × a-j 行 + 上下电源轨，每列 5 孔连通）。首次进入会自动摆放元件并按原理图网络生成全部跳线；也可用 ✨自动布线 / 📐重新摆放 / 🧹清空接线。按住孔位拖到目标孔位松开即可拉跳线；拖动只接了一根跳线的孔位 = 移动该跳线端；把 VCC/GND 拖到电源轨可给整条轨供电；DIP 按真实物理引脚跨列（电源脚位空置），按 R 翻转 180°。面包板模式下电路照常实时仿真。
  • 🟩 PCB：DIP 封装布局 + 飞线预览（按原理图网表）。拖动/旋转(R)封装后，📤 导出立创EDA 生成其标准版可直接打开的 PCB 源文件——焊盘已带网络名，打开后显示飞线，可直接使用立创EDA的自动布线；📋 导出网表 为通用网表 JSON（供未来自有布线器）。

基本操作

  • 放置元件：从左侧元件库拖拽到画布，或直接点击元件名放到视图中央。
  • 连线：按住引脚拖到目标引脚松开即可连线；中途松开在空白处取消。一个引脚可以连接多条导线（相当于并线）。拖动只连了一根线的引脚 = 移动该线端（重新接线）；此时按住 Ctrl 拖动则强制新建连线。
  • 移动 / 视图：左键拖动元件移动；右键（或中键）拖动平移视图，滚轮缩放，适配视图显示全部。
  • 旋转：选中后按 R 或右键菜单。删除：Del / 右键菜单。
  • 开关 / 按键：单击切换 / 按住导通。标签 / 时钟频率：右键元件 → 编辑标签…。
  • 存储器：ROM (256×8) 右键 → 编辑内容 / 导出 (十六进制，可粘贴导入)；RAM (256×8, CS/WE 高有效) 右键 → 获取快照 / 导出。地址悬空按 0。

电平与颜色

  • 绿色 = 高电平(1)； 灰蓝 = 低电平(0)。
  • 橙色 = 未知(X)：输入悬空、数据未知或多个输出冲突。
  • 灰色虚线 = 高阻(Z)：三态输出未使能、网络无驱动。
  • 未连接的输入按 X 处理；名称带 ~ 的低有效引脚（如 ~CLR、~OE、~G2A）读到的 X 视为"未动作"（相当于弱上拉）。
  • 连线 / 上电时引擎会对输出为 X 的门电路做一次"上电扰动"，使纯反馈环路（如环形振荡器、锁存器）能够自启动。

运行控制

  • ⏸ / ▶ 暂停或恢复时钟；暂停时手动切换开关信号仍会正常传播。
  • ⏭ 步进：每按一次使所有时钟源翻转半周期，便于逐拍观察计数器 / 触发器。
  • 速度：仿真时间倍率。状态栏显示仿真时间与累计事件数（事件数持续暴涨说明电路在振荡）。

快捷键

  • 空格 运行/暂停
  • R 旋转选中
  • Del 删除选中
  • Esc 取消连线/取消选择
  • Ctrl+Z/Ctrl+Y 撤销/重做
  • Ctrl+D 复制选中

保存

  • 电路改动会自动保存在浏览器 localStorage 中；也可通过 文件 → 导出 / 导入 JSON 备份或分享。
