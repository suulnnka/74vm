# 74VM — 74 系列数字电路模拟器

纯前端（零依赖）的 74 系列逻辑芯片电路模拟器，带**三种模式**：

- **📐 原理图模式**：拖拽芯片、点击引脚连线、实时电平仿真
- **🍞 面包板模式**：真实面包板视图（60 列、a–j 行、上下电源轨、每列 5 孔连通），**一键从原理图自动摆放元件并生成全部跳线**（含每颗芯片的供电跳线），跳线/孔位级编辑，**DIP 需接通电源轨才工作**，电路照常实时仿真
- **🟩 PCB 模式**：DIP 封装布局 + 飞线预览，**导出立创EDA(标准版)可直接打开的 PCB 源文件**——焊盘自带网络名，打开即有飞线，可直接用立创EDA的自动布线；另可导出通用网表 JSON（供未来自有布线器）

## 运行

```bash
cd 74vm
python -m http.server 8111
# 浏览器打开 http://localhost:8111
```

（直接双击 `index.html` 也可以运行；推荐 http 服务方式。）

## 功能

- **拖拽放置**：从左侧元件库拖拽或点击放置；自动寻找空位不重叠
- **连线**：点击引脚 → 点击目标引脚；一个引脚可接多条导线（并线）
- **实时电平显示**：绿=1、灰蓝=0、橙=X（悬空/冲突）、灰虚线=Z（高阻）
- **交互元件**：开关、按键、时钟源（0.1Hz~20kHz）、LED、七段数码管、逻辑探针、VCC、GND
- **4×4 矩阵键盘**：4 列 (C1..C4) + 4 行 (R1..R4)，按住键格 = 行列接通；行脚内置下拉(默认，空闲0)/上拉(空闲1)可右键切换，同时支持列高有效与列低有效(经典 74138/74145 扫描)两种极性；按下的列未驱动 → 行输出 X
- **NE555 定时器**：真实 DIP-8 封装（1 脚 GND / 8 脚 VCC，需供电）、无稳态振荡输出时钟（右键改频率，0.1Hz~20kHz）、~RST 低电平停振复位、DISCH 真实放电管行为（OUT 低电平期导通，高电平期高阻）
- **PS/2 键盘**：点击元件聚焦后用真实键盘打字，按标准 PS/2 协议（Set 2 扫描码）在 CLK/DATA 上串行发送——按下发 Make 码、松开发 Break 码（0xF0），扩展键前缀 0xE0；帧格式 = 起始位 + 8 数据位（LSB 在前）+ 奇校验 + 停止位，键盘自产 ~16.7kHz 时钟，可接 74164/7474 等搭建解码电路
- **1602 液晶**：HD44780 风格接口（RS+E+8 位数据），内置中文字库（GB2312 双字节），等宽字体渲染；右键编辑显示文本/清屏
- **1602 液晶**：HD44780 风格接口（RS+E+8 位数据），内置中文字库（GB2312 双字节），等宽字体渲染；右键编辑显示文本/清屏
- **12864 图形液晶**：ST7920 风格，文字层 4 行×16 字符（GB2312 中文字库）+ 图形层 128×64 点阵叠加；右键编辑文本/清屏/清除图形
- **PS/2 测试脚本**：键盘元件右键 → 编辑测试脚本（`type 文本` / `sleep 毫秒` / `key 键名`，# 注释），运行脚本自动按节拍打字，方便测试
- **存储器 (ROM / RAM 分类)**：ROM 类 74187 ROM 256×4、74S472 PROM 512×8（右键编辑内容，十六进制粘贴导入/文件导出）、AT28C64B EEPROM 8K×8、AT28C256 EEPROM 32K×8（真实 DIP-28 引脚与 14/28 电源脚，/WE=0 可像 SRAM 一样电改写，右键编辑/导出）；RAM 类 74189 RAM 16×4、6116 SRAM 2K×8（低有效 /CS /WE /OE 双向数据总线，右键获取快照/导出）、6264 SRAM 8K×8（真实 DIP-28 引脚，双片选 /CS1 低有效 + CS2 高有效——悬空不选中，需接 VCC）
- **仿真引擎**：事件驱动 + 门延迟，支持反馈环路（锁存器/环形振荡器自启动）、多驱动冲突、三态、振荡检测
- **面包板模式**：孔位级连通模型（列组 5 孔 + 整条电源轨）、✨自动布线（按原理图网络逐网生成跳线，电源网络自动走电源轨，**并自动为每颗 DIP 生成 VCC/GND → 电源轨的供电跳线**）、供电检查（见下方规则）、DIP 按物理引脚跨列、R 翻转、未放置元件托盘
- **PCB 模式**：2.54mm 网格 DIP/排针封装、飞线、R 旋转、自动布局、立创EDA/网表导出
- **编辑**：选择/多选、拖动、旋转、复制(Ctrl+D)、删除、撤销/重做、右键菜单、右键编辑标签；模式用顶栏或 1/2/3 切换
- **持久化**：改动自动保存（含面包板跳线与 PCB 布局）；JSON 导出/导入；16 个内置示例

## 立创EDA 导出说明

PCB 模式 → **📤 导出立创EDA** 生成 `74vm-pcb-easyeda.json`（EasyEDA 标准版源文件格式，docType=3，坐标 mil）。在立创EDA标准版：**文件 → 导入 → EasyEDA**（或直接打开该 JSON）→ 得到带网络的 PCB：焊盘带 VCC/N1… 网络名、丝印外框、板框，编辑器内显示飞线，随后即可使用立创EDA的**自动布线**。专业版可先导入标准版文件再转换。

已知限制：元件以散焊盘+丝印形式导出（非成组封装），位号文本需在EDA内补充；导出前请确保所有元件均已布局。

## 仿真规则

- 未连接的输入按 **X**（橙色）处理并通过门电路传播
- 名称带 `~` 的低有效引脚（~CLR、~OE、~G2A 等）读到 X 视为"未动作"（弱上拉）
- 多个输出接到同一网络且电平冲突 → **X**；无驱动 → **Z**
- 连线/上电时引擎对输出为 X 的门做一次"上电扰动"，使纯反馈环路能自启动
- 面包板模式：孔位连通性（列组/电源轨/跳线）派生网表，与原理图网表严格等价（有测试保证）
- **面包板供电检查**：DIP 芯片的 VCC 电源脚（物理最大脚，如 14 脚芯片的 14 脚）与 GND 电源脚（物理中间脚，如 7 脚）所在列必须跳线接通电源轨——VCC 列 → 红轨(+)、GND 列 → 蓝轨(−)，否则视为未上电：输出全部强制为 X，芯片上标注「未供电」徽标，状态栏提示数量；NE555 按真实引脚供电（lib.pwr 覆盖：1 脚 GND / 8 脚 VCC）；**AT28C64B/AT28C256/6264 为真实 DIP-28 引脚存储器**（lib.pwr：14 脚 GND / 28 脚 VCC），与其他 DIP 一样参与供电检查并自动生成供电跳线；**理想化存储模型**（74S472/6116/74187/74189，引脚为压缩编号且无电源脚）视为常供电，不参与供电检查与供电跳线；**有源虚拟元件**（时钟源、PS/2 键盘）信号脚两侧带隐式 VCC/GND 电源腿（占位宽一列），同样必须供电，未上电时时钟停振、PS2 不发送；电源轨视为已接通台式电源，通电后相连的孔位/跳线按极性显示红/蓝（+− 相碰显示橙）；✨自动布线会自动生成供电跳线并保护电源列不被信号跳线占用；无源元件（开关/按键/LED/数码管/探针/VCC/GND）与原理图模式不做供电检查
